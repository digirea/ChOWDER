tileViewer.zoomIn(onlyLevel, pixelPos, speed)

Zoom in.

Kind: instance method of TileViewer

Param Type Default Description
onlyLevel Boolean false If only the level is to be changed, set to true.
pixelPos Object Coordinates to be the center of the scaling (x, y on the viewerElem, unit: number of pixels) If null, scaling is performed at the center of the screen。
speed Number 1 Factor to be multiplied by the speed at zoom out. Valid only if onlyLevel = false. Default is 1.0.

tileViewer.zoomOut(onlyLevel, pixelPos, speed)

Kind: instance method of TileViewer

Param Type Default Description

pixelPos Object Coordinates to be the center of the scaling (x, y on the viewerElem, unit: number of pixels) If null, scaling is performed at the center of the screen。
speed Number 1 Factor to be multiplied by the speed at zoom out. Valid only if onlyLevel = false. Default is 1.0.

tileViewer.setViewport(viewport)

Set Viewport in the form [left, top, right, bottom
The Viewport is the current TileViewer drawing area as a whole.
the top left (0,0) and bottom right (1,1).
the actual display area [left, top, right, bottom].
Tiles outside this area are culled.

Kind: instance method of TileViewer

Param Type Description
viewport Array Viewport in the form of [left, top, right, bottom]

tileViewer.getCameraInfo() ⇒

Returns camera information including scale, etc.
By obtaining this value and calling setCameraInfo, the appearance can be completely reproduced.
However, the viewport must be obtained separately.

Kind: instance method of TileViewer
Returns: Camera information including all scales

tileViewer.setCameraInfo()

Returns camera information including scale, etc.
The camera position can be restored by putting the value obtained by getCameraInfo in the argument.
However, the viewport must be obtained separately.

Kind: instance method of TileViewer

tileViewer.generateScales(mapParams, geodeticSystem) ⇒

Create scale settings according to zoom ratio and geodeticSystem
In standard, scale settings are created from zoom.min to zoom.max, increasing with powers of 2.
In himawari8.jp and himawari8.fd, the pre-defined scale settings are returned.
When coast is included in the url in himawari8.jp and himawari8.fd,
returns the pre-defined scale setting for coastline

Kind: instance method of TileViewer
Returns: scale

Param Type Description
mapParams Object Object corresponding to one map listed in options.maps
geodeticSystem String Geodetic definition string

TileViewer.convertStandardLonLatToCameraCoord(lonLat) ⇒

Transforms longitude and latitude in the Mercator coordinate system into camera coordinates and returns them.

Kind: static method of TileViewer
Returns: Camera coordinates in the form { x: , y: }, where x is 0 to 1,
For y-values, 0~1, but for latitudes that do not fit in the Mercator coordinates, the value is less than 0 or greater than 1.

Param Type Description
lonLat Object Degree value in the form of { lon: , lat : }. Longitude is assumed to be -180~180, latitude -90~90.

TileViewer.convertCameraCoordToStandardLonLat(coord) ⇒

Returns camera coordinates converted to longitude and latitude in the Mercator coordinate system

Kind: static method of TileViewer
Returns: degree value in the form of longitude latitude { lon: , lat : }.

Param Type Description
coord Object Camera coordinate values in the form { x: , y: }

TileViewer.convertHimawariJPLonLatToCameraCoord(lonLat) ⇒

Himawari-8 Latitude and longitude coordinates assumed for the Japan area are converted to camera coordinates and returned.
https://www.data.jma.go.jp/suishin/jyouhou/pdf/456.pdf
Japan area: 48.5°N to 21.5°N, 119°E to 152°E
Projection method: Latitude and longitude coordinates, geodetic system conforms to WGS84

Kind: static method of TileViewer
Returns: Form of camera coordinates { x: , y: }
The x and y values are 0~1, but for latitude and longitude that do not fall within Japan, the values are less than 0 or greater than 1.

Param Type Description
lonLat Object degree value in the form of longitude latitude { lon: , lat : }.
