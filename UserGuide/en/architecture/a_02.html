API Specifications for Communication

This section describes the specifications for client-server communication.

The server receives a metabinary from the client via websocket and processes it according to the commands described in the metadata. After processing, the server sends the metabinary including the response to the client via websocket.

When a data update occurs, an update notification is broadcasted to the client.
When the display receives the update notification, it sends a content/window information request to the server to obtain the content/window information.

When a display is newly displayed, the display issues a display registration request to the server to register its own display.

Metabinary

The format of the metabinary format, which is the data exchanged between the client and server, is shown below.
The following table shows the data stored in the metabinary format, starting from the beginning.

Usage Data type Byte count
Header "MetaBin:"(string) 8byte
version UInt32 4byte
Metadata size UInt32 4byte
Metadata Ascii string(JSON) Metadata size
Content data Binary, etc. Remaining bytes

The version is usually 2 at present.

Content data contains the binary or text data of the content image.

Metadata contains JSON strings. Specifically, it contains the following values.

　　{
　　　　　　"jsonrpc" : "2.0",
　　　　　　"method" : "AddContent",
　　　　　　"to" : "master",
　　　　　　"params" : {
　　　　　　　　　　"id" : "someid",
　　　　　　　　　　"type" : image
　　　　　　}
　　}

"jsonprc" is always "2.0" now.

"method" is a command to the server (controller). See the request/response messages for the details of the commands.

"to" is the destination of the data.

  • In the case of to = master: data to be sent to the server (controller)
  • If "to = client": data to be sent to the display

"id" in "params" is the ID to uniquely identify the content.

"type" in "params" is the type of content data. Currently, the types are as follows.

value of "type" Content of contents
text UTF8 string
url URL-encoded string
image Binary image file
layout Layout information (used internally)
video Video file or streaming video
pdf PDF file
tileimage large image
webgl WebGL page
