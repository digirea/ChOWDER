About Data Storage Method

About IDs

Content information and window information are stored by assigning content ID and window ID, respectively. IDs are created with random 8-digit alphanumeric characters at the time of content storage on the server, and can be added by specifying an arbitrary ID to an add method such as "AddContent".

Storage Format

Image data and text data are stored as binary or UTF8 strings as they are sent from clients. URLs are stored as binaries of image data rendered by phantom.js.

Metadata added by the server

The image data is saved on the server side with mime automatically detected. For images rendered by phantomjs, posx, posy, width, height, orgWidth, orgHeight, and mime are added on the server side.

About reference counts

Since contents and windows may be referenced from multiple metadata or displays, reference counts are maintained on the server side.

About user data

User data (meta information) is stored in the content metadata as user_data_text.

user_data_text is in JSON text format and holds the following key-value values.

{
            text : "The text entered in the meta information is stored here."
}
