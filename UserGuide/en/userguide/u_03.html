ChOWDER Home Screen

Explanation of the home screen

To access ChOWDER, type 「 http://localhost/ 」in the address field of your web browser after starting the application as described above.
After accessing ChOWDER, the home screen shown above will be displayed.
ChOWDER has the following two modes (Display, Controller), and the home screen determines which mode to use.

  • Controller: After the login screen, the user is redirected to the controller screen.

  • Display : Moves to the display screen.

As described above, you can choose whether to use the accessed PC as a "Controller" or as a "Display".

Login Screen

Overview

On the login screen, enter the user role (privileges), display name, and password for the "controller.


On the controller login screen, enter the user role (authority), display name, and password in the "Controller" field. Only when the "Controller" and "Password" match, login is possible. The display name can be entered freely.

Controller Authority and Administration

Controller Authorization

There are the following types of controllers, and passwords and access privileges can be set for each controller.

Type Overview Access
Administrators Administrators with access to all functions All functions including the admin screen
Groups Permissions for each content group Subject to access restrictions set in the administrator's screen By default, only the group and default can edit and view content.
Moderator Sub administrator with access to most functions All functions, including admin
Attendee General user who can add and manipulate content All functions except admin

Special Permissions
Guest and Display can be used without password and only access privileges can be set.

Type Overview Access
Guest Allows entry without password By default, only default allows editing and browsing, subject to the access restrictions set in the administrator screen.
Display Permissions when connected to Display By default, all groups can be edited and viewed, subject to the access restrictions set on the administrator screen.

Management screen

By logging in to the controller as an administrator, you can access the management screen from the Management menu.
The administration screen is accessible from the Management menu. On the administration screen, you can access the controller privileges and configure various settings.

*Management screen Menu*
*Management screen*

DB Management

In DB management, you can create, switch, rename, delete, and initialize a storage area. However, you cannot rename or delete the storage named "default" which is created automatically at first.

*DB management*

History Management

In the history management, you can set the maximum number of contents replacement history to be saved. The number of history records for each content is set here. This value is a global setting, and the same value is applied even if the DB is changed.

*History management*

View/Edit Permission Settings

In the "permissions" section, you can set permissions for each controller.

*Setting permissions to view/edit*
  1. Select a controller to be set.
  2. Select the content group that the selected controller can edit and the content group that the selected controller can view. If you select "All", newly created groups are also viewable and editable.
  3. Select the sites which are editable by the selected controller. If you select "All", then newly created sites are also viewable and editable.
  4. Whether or not the selected controller is allowed to edit or display the group.

Password setting

In the password settings, you can change the password of the controller.
The previous password is required only if you change the administrator's password.

*Password setting* You cannot log in to `Moderator` and `Attendee` until you set the password with this setting. If you want to use `Moderator` and `Attendee` privileges, please be sure to set the password with the Admin privilege user in advance.

Display Settings

In the display settings, you can change the permission settings for content delivery.
Content will be delivered only to authorized displays.
