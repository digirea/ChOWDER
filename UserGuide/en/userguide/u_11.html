Using TileViewer

Overview

Using the 2D TileViewer, you can register satellite images of the Sunflower meteorological satellite and map data in Web Mercator format as ChOWDER contents and draw them on the ChOWDER display.

How to use the application

You can access the following URL to use the TileViewer functions.

  • URL for HTTP … http://ChOWDER_Server_Address/tileviewer.html
  • URL for HTTPS … https://ChOWDER_Server_Address/tileviewer.html

Select the APIUser password and the file to be used, and log in.

Select the APIUser password and the preset to be displayed, and log in.

When the content is successfully loaded, the displayed preset will be added as a ChOWDER content at the same time.

    1. The time (date and time) of the displayed content will be shown, and the date and time can be changed.
    1. From left to right: Display Layer Menu, Display Help, Enable Remote Cursor, and Change Remote Cursor Color button.
    1. Play/Stop button for time (date/time).
    1. Specifies the scale of the timeline.
    1. Enables/disables the range bar on the timeline.
    1. Timeline. Allows manipulation of the time (date/time).
    1. A toggle button that toggles whether or not the time in the timeline is synchronized between content.

Layer Menu

    1. Content ID is displayed
    2. The URL of the preset that is the source of the content is displayed.
    3. The layer list containing the current content is displayed.
    4. From left to right: move layer order up, move layer order down, add new layer, delete new layer.
    5. The tile URL of the layer is displayed.
    6. From the top, it is the setting of layer visibility (visible) and the setting of layer opacity (opacity).
    7. Set the copyright information (name, URL) to the layer. If set, it will be displayed in the upper left corner of the content.
    8. Show/hide the time label in the upper left corner of the content.
    9. Toggles the zoom label in the lower right corner of the content.
    10. Selects whether the zoom rate is fixed for all controllers/displays.
    11. Allows you to set a fixed zoom rate when the zoom rate is set to fixed.

Add Layer Function

By clicking the Add Layer button, a layer can be added in the Add Layer dialog.

The types of layers that can be added and how to specify the URL are as follows

  • standard : Layer with EPSG3857 color tiles
    • For URL, specify https://server-address/{z}/{x}/{y}.png etc., and specify the tile number part by {x}{y}{z} or %x%y%z.
    • ZOOM specifies the range (MIN, MAX) over which the data source is to be expanded. This corresponds to {z} in the tile URL.
  • himawari8.jp : Layers by Japan area of the Himawari 8 meteorological satellite Specify
    • https://localhost/himawari8/img/D531107/%cd/%w/%YYYY/%MM/%DD/%hh%mm%ss_%x_%y.png and so on for URL. Variables for % are described below. As for the time (%hh%mm%ss), values are inserted every 2 minutes and 30 seconds.
  • himawari8.fd : Full disk format layer of the Himawari 8 satellite
    • https://localhost/himawari8/img/D531106/%cd/%w/%YYYY/%MM/%DD/%hh%mm%ss_%x_%y.png and so on. The % variables are described below. For time (%hh%mm%ss), values are inserted every 10 minutes.
  • background image : Add a background image. Or replace the existing background image.
    • The URL should be https://localhost/backgroundImage.png etc.
  • other : Used for preset images that do not belong to the above.

The meanings of the % and {} variables are as follows

  • {x}{y}{z} or %x%y%z : Indicates xy and zoom rate z of the tile number.
  • %c : Indicates the dimension of the Sunflower 8 image
  • %w : Indicates the width of the image. It will be replaced by the image width described in SCALES when the image is acquired.
  • %YYYYY%MM%DD : Indicates year, month, and day.
  • %hh%mm%ss : Indicates hour, minute, second

How to set up and operate a timeline for TileViewer

The timeline for TileViewer uses k2go Timeline ( https://www.k2go.jp/public/Timeline/ ), which allows you to specify the time corresponding to the data, playback, stop, etc.

When the RangeBar button on the bottom left is clicked and enabled, a range bar can be specified to control the playback area.

Also, when the Sync button on the bottom right is enabled, the time information from the timeline operation will be transmitted to all other TileViewer content for which Sync is enabled. The Sync button can be toggled enabled/disabled by pressing the button.

Configuring Presets for TileViewer

Presets for TileViewer are defined by json files stored in

  • Preset list definition file : public/sample_data/tileviewer/preset_list.json
  • Preset definition file : public/sample_data/tileviewer/settings/osm.json 等

Preset list definition file

"url": "sample_data/tileviewer/index.html?json=xxxx"
with the name of the preset definition json file in the "xxxxx" part.

For example, for a preset that uses osm.json, specify the following

{
    "preset_list": [
        {
            "name": "OpenStreetMap",
            "url": "sample_data/tileviewer/index.html?json=osm"
        }
    ]
}

This will cause the OpenStreetMap preset to appear in the preset list when accessing the Tile Viewer, allowing the use of tiled maps using the definition information in osm.json.

Preset Definition File

The preset definition file contains the URL of the map and other information to create a state when the preset is loaded.

//  An example of a preset definition file (json)
{
    "backgroundImage": "https://cyberjapandata.gsi.go.jp/xyz/std/0/0/0.png",
    "maps": [{
        "url": "https://cyberjapandata.gsi.go.jp/xyz/std/%z/%x/%y.png",
        "zoom" : {
            "min" : 0,
            "max" : 18
        },
        "attribution":  {
            "name" : "出典：国土地理院",
            "url" : "https://maps.gsi.go.jp/development/ichiran.html"
        },
        "opacity": 1.0,
        "visible" : true
    }],
    "geodeticSystem": "standard",
    "initialPosition" : {
        "center": {
            "degrees": {
                "lon": 139.69167,
                "lat": 35.68944
            }
        }
    },
    "timeout" : 0,
    "timeout_on_setting_date" : 5000,
}
  • backgroundImage : Specify the URL of the background image.
  • maps : Define layers as an array. The following settings are available for each layer
    • url : Specify the URL of the tile map
    • zoom : If the geodeticSystem is standard, set the minimum and maximum zoom value.
    • scales : If the geodeticSystem is other than standard, set the map information for each zoom level. (Refer to himawari_jp.json etc.)
    • attribution : Specify the name (name) and URL (url) of the copyright information.
    • opacity : Specify the opacity immediately after loading the preset. Default is 1.0.
    • visible : Specify the state of visibility immediately after loading presets. Default is true.
  • Specify the coordinate system of this preset. standard (for EPSG3857) himawari8.jp (for Himawari8 in Japan) himawari8.fd (for Himawari8 in full disk) are available.
  • initialPosition : Initial camera position can be specified in latitude and longitude.
  • timeout : Set the maximum waiting time in milliseconds to wait for tile display completion during normal operation. Default is 0.
  • timeout_on_setting_date : Maximum waiting time in milliseconds to wait for tile display completion when time is changed. Default is 1000.
