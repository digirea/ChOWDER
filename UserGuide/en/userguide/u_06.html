Display Screen Operations

Overview

This section explains how to operate the display. Each tab, window, and function is explained.

Display Operations: Menu

In the display, a menu appears when you touch the screen with the mouse or with a tablet. In the menu, several operations can be performed.

Switching to the controller screen

You can switch from display mode to controller mode.

Switching to full screen

You can switch between window mode and full screen mode. To return from full screen to window mode, select the same menu again or press the ESC key.

Setting Display ID

You can set the ID of the display that can be recognized by the controller. After entering any character string, press the Enter key to set it.

VR Display

VR Mode

When a ChOWDER page is displayed from the HMD device's web browser, it is recognized as a VR display and WebXR allows the user to switch to an immersive VR mode.

Switching to VR mode

When the ChOWDER page is displayed on the HMD device, it is registered on the ChOWDER server as a new VR display, so it is necessary to set the permission on the controller first.

If the VR display is permitted, the VR Display button will appear, and pressing it will shift to the immersive VR mode.

Setting up VR mode

In the "basic server settings", you can switch the VR mode display method by specifying the VRMode in setting.json.

Planar mode

In planar mode, a planar ChOWDER display is placed in front of the initial viewpoint position. The display is 3840px wide and 2160px high, and is positioned to provide a view of approximately 114 degrees horizontal viewing angle and 120 degrees vertical viewing angle from the initial viewpoint position in still mode.

Curved Surface Mode

In curved mode, a cylindrical rectangular area with a horizontal viewing angle of approximately 180 degrees and a vertical viewing angle of 120 degrees is placed in front of the initial viewpoint position. The display is 3840px wide and 2160px high.

360-degree mode

The 360-degree mode extends the curved surface mode to a 360-degree cylindrical area. Within the rectangular area, the display is 7680px wide and 2160px high.

Operation in VR mode

In VR mode, you can use the hand controller of the VR device to select, move, zoom in and out, highlight and cancel the contents frame, and display and cancel the memo. The method of each operation is as follows.

Operation Controller operation
Content Selection Move the cursor to the content and pull the trigger (PrimaryIndexTrigger).
Deselect Contents Pull the trigger (PrimaryHandTrigger) of the controller that selected the contents.
Move Tilt the controller in the direction you want to move it with the content selected.
Expand Tilt the controller and pull the cursor away while pulling the PrimaryIndexTrigger on the left and right controllers for the same content.
Reduce Tilt the controller while pulling the PrimaryIndexTrigger on the left and right controllers for the same content, and move the cursor closer.
Highlighting and de-emphasizing the content frame After selecting the content, select the "☆" button with the PrimaryIndexTrigger.
Highlighting and de-emphasizing a memo After selecting the content, select it by triggering the "i" button (PrimaryIndexTrigger).

Limitations of VR Mode

About the display area

In VR mode, content is displayed until it completely exits the display area. In addition, when moving content using a hand controller in VR mode, content can only be moved within the display area.

Displaying WebGL content (content using iTown)

There is a problem that WebGL contents are displayed black when newly added while in VR mode display. As a workaround, exit VR mode once, wait a few seconds, and re-enter VR mode.

Displaying PDF contents

There is a problem that PDF contents are not displayed when newly added while in VR mode. As a workaround, exit VR mode once, wait a few seconds, and re-enter VR mode.

About still images with alpha (transparency)

For still images with alpha values, the threshold value is 0.5 to switch between displaying the image completely or making it transparent. (Alpha test) No blending of alpha values is performed, and the areas containing alpha are displayed or hidden.

About Animated GIF format images

Animated GIF format animated displays are not supported in VR mode.
