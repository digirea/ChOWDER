Operations at the bottom of the controller screen

Display tab

Displays a list of VirtualDisplays and Displays connected to the ChOWDER server.
The controller can place this Display on the VirtualDisplay.
By adding Contents on the placed Display, a workspace for sharing Contents is realized.
Displays can be placed on the VirtualDisplaySpace by dragging and dropping them with the mouse.
The above figure shows an example environment with a client connected.

In the NewDisplays column, newly accessed Displays are displayed, and you can specify whether to allow or disallow content delivery to the new Display.
Until you allow it, no content will be delivered to the Display side
Once selected, the information is saved and the next access will be delivered according to the saved permission information.

Virtual Display Settings

Setting the number of divisions

When you select "Virtual Display" in the "Display" tab, you can configure the settings of the Virtual Display in the Property window. In the above figure, the Virtual Display is set to 1500 pixels in width, 1500 pixels in height, 2 horizontal divisions, and 2 vertical divisions.

snap function

There is a "snap function" to precisely place a Display in a compartment.
The mode can be changed from the drop-down list shown in the figure below.

  • Free : Free placement.
  • Display : Display and Contents will be snapped to the placed Display.
  • Grid : Displays and Contents will be snapped along the partitioned sections by VirtualDisplaySetting.

The following figure shows a legend for placing a display using the snap function.

Another VirtualDisplaySpace scaling option is the Scale function.
By holding down the right mouse button and dragging within the screen, the entire screen can be scaled.

Display and ID

IDs of connected displays are displayed on each connected display so that they can be identified.
The ID is unique to each connected terminal and one ID is assigned to each terminal.

Delete button

Deletes the selected Display (disconnects from the ChOWDER server).

※VirtualDisplay cannot be deleted.

Select All button

Selects all connected displays.

DisplayGroup settings

In the Display tab, you can configure the DisplayGroup settings to be assigned to the display. Each DisplayGroup can have one Virtual Display.

The button "Add" allows you to add a group, and the order of the created groups can be changed. You can also rename, change the group color, and delete a group by clicking on the "Settings" menu.


Assigning DisplayGroup

You can change the group assigned to the display from the right-click menu of the display or the menu at the lower right corner of the screen. However, the group of VirtualDisplay cannot be changed.

Content tab

In this application, Contents are displayed on the display by dragging and dropping them from the Contents tab at the bottom of the screen.

Displaying Contents

Contents can be displayed by dragging and dropping them from the Contents list to the VirtualScreen area in the center of the screen.

Manipulation of Contents

The added Contents can be selected by left mouse click, or multiple contents can be selected by Ctrl + left mouse click. When selected, manipulators and buttons for manipulation are displayed (see the figure below).

  • Buttons for manipulation during selection
    • Highlight button ... highlights the selected contents.
      The highlighted contents are shown with a group-colored thick frame in the Display.
    • Show meta information button ... shows the meta information of the selected contents on the Display side.
    • Hide button ... Hide the content from VirtualDisplaySpace.
      You can drag the hidden contents from the contents list to show them again.

Group Settings

In the Content tab, you can set up a Group to be assigned to the contents. Groups can be added and reordered by clicking the "Add Group" button. You can also rename, change the group color, or delete a group by clicking on the "Settings" menu.


Assign Group

Groups assigned to contents can be changed from the right-click menu of the contents or the menu in the lower right corner of the screen.

Search Tab

The Search tab allows you to search for added contents.

Metadata Search

The text box on the Search tab allows you to search for metadata. The search will be performed for the group whose checkbox is checked.

Layout Tab

The Layout tab allows you to save the current content display as a Layout.

Adding a Layout

A Layout can be added from the right-click menu in the Layout list at the bottom of the screen, or from the menu in the lower right corner of the screen. Additions are made to groups whose checkboxes are checked.

Overwrite Layout

Overwrites the current content display state to the currently selected layout.

Change Group

Change the group to which a Layout belongs.

Apply Layout

Apply a Layout by dragging and dropping the Layout content from the Layout list at the bottom of the screen onto the screen.

Users Tab

The Users tab allows you to view a list of users who are logged in to the current ChOWDER controller.

User Button

Clicking on the name of a logged-in user in the Users tab will automatically take you to the Content tab with all content added by that user selected.

Property Window

The Property window displays the selected Contents, Display, ContentsID, and their respective Properties.
The properties can be edited except for the ID as shown below, and the coordinates, display priority ( Zindex ), and the topmost display enforcement can be specified.
Selected contents can be downloaded from the download button at the bottom of the Property window.

Manipulation of Video Contents

When a video content is selected on the controller that holds the video data, controls for operation are displayed in addition to the normal content controls.

Video Controls/h3>

On the controller that holds the video, the following controls are displayed for the video content.

Each control allows you to

  1. Play and pause the video
  2. Seek video
  3. Audio control on the controller PC
  4. Video transmission ON/OFF
  5. ON/OFF of audio transmission

Video Settings

When video content is selected on the controller holding the video, the Property window allows you to switch capture devices and configure delivery settings.

You can configure the following settings

  1. Change the video input device (only available for camera-based video content).
  2. Change the audio input device (only available for video content from the camera).
  3. Video quality settings.
    Manual Allows you to set the bit rate of the video streamed by WebRTC. (*1)
    Full size:Switches to delivery mode using WebRTC Datachannel, allowing video to be delivered in full size and without degradation (*2)
  4. Audio quality setting allows you to set the bit rate of the audio streamed by WebRTC. (*1)
  5. Refer to the WebRTC quality information stored in the content metadata.(*1)

(※1)
The bit rate set here will be used as the bit rate at the start of delivery.
The bit rate is automatically changed by WebRTC to the optimal bit rate at the time of delivery, so the bit rate set here will differ from the actual bit rate.

(※2)
Full-size option is available only when video files are delivered.

Batch operation of videos

Video content in the same group can be played, paused, or cued in a batch.
To do this, follow the steps below.

  1. Right-click on the Content tab → Batch control of videos in a group
  2. Use the video batch control controller displayed at the bottom of the screen.

Controller Authority and Administration

Controller Authorization

The following controller types are available, and passwords and access privileges can be set for each controller.

Type Overview Access
Administrator Administrator who can access all functions All functions including administration screen
Group Authorization for each content group By default, only the group and default can be edited and viewed, subject to the access restrictions set in the administrator's screen.
Moderator Sub administrator with access to most functions All functions, including admin
Attendee General user who can add and manipulate content All functions except admin

Special privileges
Guest and Display can be used without password, and only access privileges can be set.

Type Overview Access
Guest Guest Allows entry without password By default, only default can edit and browse, subject to the access restrictions set in the administrator screen.
Display Permissions when connected to Display By default, all groups can be edited and viewed, subject to the access restrictions set on the administrator screen.

Management screen

By logging in to the controller as an administrator, you can access the management screen from the Management menu. On the management screen, you can access the controller privileges and configure various settings.


DB management

In DB management, you can create, switch, rename, delete, and initialize a storage area. However, you cannot rename or delete the default storage area which is created automatically at first.

History Management

In the history management, you can set the maximum number of contents replacement history to be saved. The number of history records for each content is set here. This value is a global setting, and the same value is applied even if the DB is changed.

View/Edit Permission Settings

In the "permissions" section, you can set permissions for each controller.

  1. Select a controller to be set.
  2. Select the content group that the selected controller can edit and the content group that the selected controller can view. If you select "All", newly created groups are also viewable and editable.
  3. Select the sites which are editable by the selected controller. If you select "All", then newly created sites are also viewable and editable.
  4. Whether or not the selected controller is allowed to edit or display the group.

Password setting

In the password settings, you can change the password of the controller.
The previous password is required only if you change the administrator's password.

*Password setting* *Password setting (for non-admins)* For `Moderator` and `Attendee`, you cannot login until you set the password in this setting. If you want to use `Moderator` and `Attendee` privileges, please be sure to set the password with the Admin privilege user in advance.

Display Settings

In the display settings, you can change the permission settings for content delivery.
Content will be delivered only to authorized displays.
