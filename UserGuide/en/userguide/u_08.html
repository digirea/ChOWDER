Using Google Chrome Extension

Overview

Google Chrome has a mechanism to extend its functionality called Extension. By adding a dedicated Extension for ChOWDER to Google Chrome, you can capture the web browser screen in real time and add it as content.

Installing the Extension

To install and add an extension to Chrome, you need to use the Chrome extension in developer mode.

  1. Open the browser's extensions page as shown below.
  2. Enable the Developer Mode toggle to enter developer mode.
  3. Restart Chrome and then open the extensions page again.
  4. On the extensions page, click on the menu item "Load Unpackaged Extensions" and select the ChOWDER/chrome_extension directory to add them.

Capturing with Extension

Once you have added an Extension, you can click on the icon to start capturing.

  • Extension's menu

    • Capture ... Capture the currently displayed web page and send it to ChOWDER.

    • AutoCapture ... Capture the currently displayed web page and send it to ChOWDER continuously at the set time interval.

    • Setting ... opens the setting menu.


  • Extension settings

    • URL ... set the URL to connect to ChOWDER.

    • Interval ... set the capture interval used by AutoCapture.

Using ChOWDER Desktop Capture

Overview

ChOWDER Desktop Capture allows you to add the entire desktop, active application window, or selected area as image content to ChOWDER.

Installation and Operating Environment

Running the installation script

On Mac
Run the following shell script under desktop capture

   $cd desktop_capture
   $sh make$app.sh

On Windows
Execute the following file under desktop capture.

   >cd desktop_capture
   >make$_app.bat

Operating environment

OS : Windows7, MacOSX 10.10

How to use ChOWDER Desktop Capture

ChOWDER Desktop Capture allows you to perform the following operations

  • Selecting and sending a capture target/range
  • Set the interval for sending captured images
  • Set the destination URL for captured images
  • Set the group to which captured images will be sent

Selecting capture target/range

Selecting Capture Targets

ChOWDER Desktop Capture will create thumbnails of the following items and display them at the bottom of the screen upon startup.

  • Entire Desktop
  • active window

Capture targets can be changed by clicking on a thumbnail. The clicked target is displayed as a preview at the top of the screen and is ready to be captured.

After selecting the capture target, press the "Capture Start" button to start sending images to ChOWDER.


Selecting the Capture Range

In ChOWDER Desktop Capture, you can send a part of the screen as an image to ChOWDER by selecting an area.

After the "Set Capture Area" button is pressed, ChOWDER Desktop Capture will be minimized and the mouse cursor will change to an indicator for range selection. After dragging the mouse cursor to the area to be captured, release the mouse button to specify the area to be captured.



Transmission of the image is started by clicking the "Capture Start" button in the same way as "Select Capture Target".

Capture Interval Settings

ChOWDER Desktop Capture allows you to set the interval for sending images to ChOWDER, which is changed by entering a numerical value in the form to the right of Capture Interval(sec) or by pressing the up/down buttons. The minimum interval is 0.05(sec). The initial value (1 sec) is entered by pressing the "Reset" button.

The values for Capture Interval, CHOWDER URL, and Target Group will be retained at the next startup even if this application is exited.

Captured Image Destination URL Settings

ChOWDER Desktop Capture allows you to set the destination (ChOWDER) URL for images, which is changed by entering the destination URL in the form on the right side of ChOWDER URL. Click the "Reset" button to enter the initial value.

Setting up groups of captured images

ChOWDER Desktop Capture allows you to set the destination group for captured images, which can be selected from the drop-down list on the right side of Target Group. The default value is entered by clicking the "Reload" button.

Using Google Chrome Extension for WebRTC

Overview

Using WebRTC, a function of HTML5, you can distribute video contents by screen sharing.
Although screen sharing is not normally possible with Google Chrome due to security restrictions, installing the Chrome Extension will enable video distribution.

Installing the Extension

To install and add an extension to Chrome, you must use Chrome Extension in developer mode.

  1. Open the Extensions page of your browser as shown in Installing an Extension.
  2. Enable the Developer Mode toggle to enter Developer Mode.
  3. Restart Chrome and then open the extensions page again.
  4. On the extensions page, click on the menu item "Load Unpackaged Extensions" and select the ChOWDER/chrome_extension_for_webrtc directory to add the extension.

If the ChOWDER server is running on a different PC

You need to add the server URL to "matches" in chrome_extension_for_webrtc/manifest.json. If you change it, you need to reinstall the extension.

[before]
  "externally_connectable": {
    "matches": ["*://127.0.0.1/*", "*://localhost/*"]
  },

[after]
  "externally_connectable": {
    "matches": ["*://127.0.0.1/*", "*://localhost/*", "*://any.somedomain.co.jp/*"]
  },

Capturing with Extension

Once you have added an Extension, you can start capturing by going to Add→ScreenShare and entering the ExtensionID in the dialog box.

Using Large-Scale Image Data Transmission Applications

Overflow

Huge image data can be sent to the ChOWDER server via a CLI application.

Application Configuration

A configuration file can be used to specify the number of divisions and content IDs/groups. The configuration file is created under the tileimage directory with the file name config.json.
The format of the configuration file is as follows::

{
    "id": "APIUser",
    "password": "password",
    "url": "ws://localhost:8081/v2/",
    "xsplit": 8,
    "ysplit": 8,
    "contentid": "contentid",
    "contentgrp": "default",
    "reload_latest" : true,
    "visible" : true
}
  • id is fixed to the APIUser.
  • Specify the password of the APIUser in " password ". The password can be changed from the password settings on the administration page.
  • Specify the URL of the ChOWDER WebSocket server in " url". Specify the URL not as a browser URL, but in a form that can be accessed from inside the server. Basically, ws://localhost:{port number}/{chowder folder location in the server}/v2/.
  • xsplit and ysplit can be used to specify the number of horizontal and vertical image splits, respectively.
  • contentid and contentgrp can be content ID and content group, respectively.
  • reload_latest can be set totrue or false to specify whether or not to continue displaying the latest images registered using the --metadata option, in Display.
  • visiblespecifies whether the registered images are visible or invisible by true or false.

How to use the application

Execute the following command from the command prompt or terminal. Specify the path to the image to be sent using the command argument.

For Mac/Linux

Run the following shell script under the bin directory 

./tileimage.sh

For Windows

Execute the following command under the bin directory.

tileimage.bat

Command options

  • --config (optional): You can specify the path to the configuration file. By default, tileimage/tileimage.json is used.
  • --metadata(optional): allows you to set image metadata.

An example command is: tileimage/tileimage.json:

./tileimage.sh --config=conf.json --metadata="{\"key\":\"value\"}" image.jpg
