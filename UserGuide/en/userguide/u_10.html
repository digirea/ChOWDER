Using the WebGL Distributed Rendering Functio

Overview

Using iTowns, a GIS drawing library, GIS content can be drawn on a ChOWDER display using WebGL.

How to use the application

Access the following URL to use the WebGL distributed rendering function.
For HTTPS URLs, you need to add an exception.

  • URL For HTTP … http://ChOWDER_Server_Address/itowns.html
  • URL For HTTPS … https://ChOWDER_Server_Address/itowns.html

Choose your APIUser password and the preset you wish to view, and log in.
When the content is successfully loaded, the displayed preset will be added as a ChOWDER content at the same time.

    1. The registered content ID will be displayed.
    1. The URL of the preset will be displayed
    1. GIS layers that can be operated are displayed.
    1. GIS layers can be added and deleted.
    1. GIS layer properties can be manipulated.
    1. Performs display performance measurement functions
    1. For time-aware content, time changes made by timeline operations are reflected.

Add GIS Layer Function

By clicking the Add Layer button, a layer can be added in the Add Layer dialog.

The types of layers that can be added and how to specify the URL are as follows

    s
  • Color : Layer by EPSG3857 color tile
    • http://server-address/{z}/{x}/{y}.png etc., and specify the tile number part by {x}{y}{z}.
  • Elevation : Layer with EPSG4326 elevation tiles and Geographical Survey Institute map DEM tiles
    • http://server-address/{z}/{x}/{y}.txt etc., and specify the tile number part by {x}{y}{z}.
  • 3DTile : Layer by 3D Tiles(b3dm) format
    • http://server-address/tileset.json Specify the json address, e.g. http://server-address/tileset.json
  • 3DTiles Timeseries : Layer with 3DTiles of time series
    • Specify the json address, e.g. http://server-address/timeseries.json (see below for how to write json)
  • PointCloud : Layer with point cloud data created by potree Converter
    • Specify the json address ashttp://server-address/cloud.json etc.
  • PointCloudTimeSeries : Layer with point cloud data of time series created by potree Converter
    • http://server-address/timeseries.json etc. and specify the json address (json description method is described later)
  • VectorTile : Vector tiles such as pbf
    • Specify the address of the vector tile, e.g.http://server-address/vectortile.pbf
    • Specify style.json for vector file, such ashttps://server-address/style.json
  • Bargraph : Layer to create a bargraph from an arbitrary CSV file
    • http://server-address/data1.csv and specify the address of the CSV file, or upload it from a local file by Import CSV File
    • http://server-address/setting1.json and specify the address of the JSON file for configuration, or upload from a local file by Import JSON File
  • OBJ : Layer mesh data in Wavefront OBJ format
    • Specify the address of the OBJ file, e.g. http://server-address/teapot.obj
    • Specify the address of the MTL file, e.g. http://server-address/default.mtl

The ID is set to a name that will appear in the layer list. It must be a unique name.

ZOOM specifies the range (MIN, MAX) to which the data source is to be expanded. This corresponds to {z} in the tile URL.

The json file to be specified as timeseries.json should be written as follows

  • The time history is described in ISO8601 notation as a key.
  • For 3DTiles, enter the address of the timeserieset.json as the value.
  • For PointCloud, the value is the address of cloud.json.

In Type 3DTiles and 3DTiles Timeseries, you can specify the EPSG code for coordinate transformation when loading. The method of specifying the EPSG code is as follows

  • Conversion : From ・・・ Select or input the EPSG code of the data.
  • Conversion : To ・・・ Select or input the EPSG code of the data to be converted.


GIS Layer Properties

The following properties can be set from the GUI for each added layer type

  • Common to all layers
    • attribution - An arbitrary name or URL to identify the copyright holder of the data source.
  • color - any name or URL to indicate the copyright holder of the data source
    • visible - visibility
    • opacity - Opacity
  • Elevation
    • scale - Elevation scale factor
  • 3D Tiles
    • visible - Visibility is hidden
    • opacity - Opacity
    • wireframe - wireframe visible/hide
    • sseThreshold - threshold used for LoD processing
    • offset tu, offset uv, offset u, offset v - Tangential position offset
    • offset w - rotation offset around axis
  • PointCloud
    • visible - display hidden
    • bbox - bounding box visible/hide
    • opacity - opacity
    • size - point size in screen space
    • sseThreshold - threshold used for LoD processing
    • offset tu, offset uv, offset u, offset v - position offset in tangent direction
    • offset w - rotation offset around the axis
  • Bargraph
    • Time - select CSV column name containing ISO8601 time string
    • Latitude - select CSV column name containing latitude values
    • Longitude (Longitude) - Select a CSV column name that contains longitude values.

How to Setup and Operate Timeline for GIS

The timeline for GIS allows you to specify the time corresponding to the data, as well as play and stop the timeline. An area called a range bar can be specified on the timeline, which ChOWDER uses as a display range for the data.

    1. Play/Stop button - Play/Stop the timeline.
    1. Range Bar - Used in ChOWDER as a range for displaying data.
    1. Sync Button - Determines if the timeline time is synchronized between several different iTowns contents.
      By default, the timeline is in sync
    1. Settings button - allows the user to set the display range of the timeline and the range of the range bar.

The range setting GUI for the settings buttons is as follows

    1. Timeline start and end date/time settings - these are usually changed automatically by scrolling the timeline or resizing the window.
    1. Set the start and end date/time for the range bar - sets the valid range for the data display

For more information on the data that corresponds to the timeline and what can be shown or hidden, please see below.

  • Bargraph

    • Displays a bar graph if the value in the column specified as time is a timestamp before the timeline time
    • If the timestamp is after the timeline time, the bargraph will be hidden.
    • If there are multiple timestamps before the timeline time, all the relevant bars are displayed.

  • 3DTiles Timeseries

  • PointCloudTimeSeries

    • If the timestamp specified in the json is before the timeline time, the data will be displayed.
    • If there are multiple timestamps specified in the json, only the data with the closest past timestamp will be displayed.

Controller Settings

The controller cannot control the camera or other aspects of the GIS content, but it can display and hide time information on the timeline in addition to the usual content settings
